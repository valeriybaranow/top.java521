Настройка SQL Server на прием подключений
Включите TCP/IP см. скриншот:

В SQL Server Configuration Manager → Сетевые настройки SQL Server → Протоколы для <ваш_экземпляр>.

Включите TCP/IP (правой кнопкой → Включить).

Проверьте порт:

Откройте свойства TCP/IP → вкладка IP-адреса.

Для IPAll укажите TCP-порт: 1433 (или другой, если используется нестандартный).
см. скриншот

Перезапустите SQL Server:

Остановите и снова запустите службу SQL Server.
